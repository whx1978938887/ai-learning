# 文件管理与版本历史

## 本地仓库

本地仓库是应用长期保存和管理文档的主要目录。这里的文件具备真实本地路径，可以重命名、复制、移动、删除、记录版本，并可选同步到 Git 仓库。

![本地仓库文件列表](https://hupingzhi.cn/materials/asset_5cf1be4337844601b9071f9697a52eac/04-files-01-notebook.png)

页面标题会显示当前位置，例如：

`本地仓库 > 项目资料 > 接口文档`

点击面包屑返回上级，点击文件夹进入下一级。顶部提供新建文件夹、搜索和排序。

## 新建和整理文件

点击底部“创建笔记”，应用会在本地仓库根目录创建 `笔记001.md` 等编号文件，并直接进入编辑模式。

点击文件或文件夹右侧的操作入口，可根据对象和权限使用：

- 重命名
- 复制
- 移动
- 文件信息
- 版本历史
- 删除

![文件操作菜单](https://hupingzhi.cn/materials/asset_9994756bae9b41389e84a39cfdbed2b4/04-files-02-file-actions.png)

长按条目进入批量选择。选中多个项目后，可批量复制、移动或删除；文件信息只在选中单个项目时显示。

## 最近打开和文件清理

“最近打开”包含本地仓库、系统文件选择器和其他应用提供的文件。

- “从最近移除”只删除最近记录，不删除原文件。
- 系统 URI 是否支持重命名或删除，取决于来源授予的权限。
- 更多菜单中的“文件清理”可以批量处理最近条目；本地文件会被实际删除，操作前请确认。

## 开启本地版本管理

本地版本管理默认关闭，历史只保存在手机本地，不会因为开启该功能而上传网络。

1. 从首页更多菜单或“用户设置”进入“版本管理与 Git 云同步”。
2. 开启“本地版本管理”。
3. 应用将当前本地仓库记录为首次基线。

保存、新建、删除、重命名、移动或导入后，应用等待两分钟；连续操作会合并为一个自动版本。打开版本历史、恢复文件或开始 Git 同步前，也会先记录尚未提交的变化。

## 查看和比较版本

在阅读页或文件操作菜单中选择“版本历史”，可以预览历史内容、逐行比较和恢复。

![单个文件的版本历史](https://hupingzhi.cn/materials/asset_6a063b25f4ae4a77a3304db59ee9199e/04-files-03-version-history.png)

![当前内容与历史版本比较](https://hupingzhi.cn/materials/asset_cf5d8b9c00b94175adde8948c08c7304/04-files-04-version-compare.png)

- 点击“创建版本”可为当前文件建立带备注的重要节点。
- 恢复旧版本前会先保存当前内容，恢复动作本身也会成为新版本。
- 在设置页打开“已删除文件”，可找回仍存在于历史中的文件。
- 外部 `content://` 文件和本地仓库之外的文件不进入版本管理；请先收录到本地仓库。

## 关闭和清理历史

- 关闭本地版本管理只停止生成新版本，不删除已有历史。
- “清除本地历史”不删除当前文档，但会不可恢复地删除历史记录。
- 已关联 Git 云时，需要先解除云关联，才能清除本地历史。

需要跨设备备份时，继续阅读[Git 云同步](06-Git云同步.md)。
