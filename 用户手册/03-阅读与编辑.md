# 阅读与编辑

## 阅读页基础操作

打开文档后会进入阅读页。顶部提供返回、文件标题、编辑/浏览切换和更多菜单。

![Markdown 文档阅读页](https://hupingzhi.cn/materials/asset_3d636403a9724c1ab3c2e8052393d790/03-reading-01-reader.png)

- 点击左上角返回上一页；从其他应用打开的文件返回后会进入“最近打开”。
- 点击顶部文件标题可以打开文档导航。
- 在更多菜单中可以搜索、分享、查看版本历史和打开阅读设置。
- 文档中的网页链接会交给系统浏览器；相对 Markdown 文件链接优先在应用内打开。
- 浏览模式和阅读模式下，双击图片可进入全屏大图，单击不会打开，以减少误触。

## 目录、书签和文档内搜索

文档中的 `#`、`##`、`###` 等标题会自动生成目录。点击标题即可跳转。

![目录与书签导航](https://hupingzhi.cn/materials/asset_ee507d345f7a4dae9fbadacdbbaab6f2/03-reading-02-navigation.png)

在阅读模式中：

- 点击底部“导航”，可在“目录 / 书签”之间切换。
- 隐藏浮动栏后，在正文区域单指向下滑动，可添加当前位置书签；同一位置再次下滑会删除。
- 页码旁出现书签图标，表示当前页已有书签。
- 阅读位置和书签只保存在本机，不修改 Markdown，也不参与 Git 同步。

需要查找文字时，在更多菜单中选择“搜索”，输入关键词后在匹配结果间切换。

## 连续滚动与分页阅读

浏览模式使用连续滚动。需要像电子书一样阅读时，点击顶部编辑按钮旁的书本图标进入阅读模式：

- 左右滑动或点击页面左右区域翻页。
- 点击页面中部显示底部“分享 / 导航 / 进度 / 阅读设置”。
- 点击“进度”查看当前页、总页数、已读百分比和累计阅读时长，也可拖动滑块跳转。
- 点击右上角浏览图标退出阅读模式。
- 代码块、宽表格和长公式仍可在内容区域横向查看。

![分页阅读的进度抽屉](https://hupingzhi.cn/materials/asset_5c4df954a11940f28c087e8e917cac88/03-reading-03-progress.png)

应用会在本机记录每个文档上次位置。再次打开时优先根据附近标题和正文恢复；可在“用户设置”关闭自动恢复。

## 主题、字体和字号

浏览模式从更多菜单打开“阅读设置”；阅读模式点击底部“阅读设置”。

![阅读设置抽屉](https://hupingzhi.cn/materials/asset_1999cad0b2624d4cbd4967792c8b2abf/03-reading-04-settings.png)

可调整：

- 主题：默认、GitHub 浅色、GitHub 深色、纸张、极简等当前内置样式。
- 阅读字体：系统字体及可按需下载的中文字体。
- 字号：使用 `A⁻`、`A⁺` 逐级调整。

下载字体会进行校验并缓存在应用内部。下载失败时请检查网络后重试。

## 轻量编辑

点击顶部“编辑”进入带格式编辑模式。内容在同一张排版画布中编辑，底部工具栏提供任务框、粗体、斜体、下划线、删除线、列表、引用、链接和代码块等操作。

![带格式编辑画布与工具栏](https://hupingzhi.cn/materials/asset_5371a6c949e44760aee396aec2a11e33/03-reading-05-editor.png)

标题、正文、引用、列表、任务框、链接和代码可直接修改。图片、表格、公式、脚注、前置内容和原始 HTML 等复杂块保持受保护显示；需要精确修改时，从更多菜单进入“源代码模式”。

带格式模式和源代码模式共用同一份未保存草稿，来回切换不会写入原文件。

### 粘贴聊天回答

如果来源应用向剪贴板提供 HTML 或富文本，MD文件阅读器会尝试转换为可编辑 Markdown；来源只提供纯文本时则保持原文。图片附件不会自动下载，表格等复杂内容会以受保护块保留。

### 保存和退出

- 点击顶部保存按钮，才会把内容写入文件。
- 切回浏览模式只会使用当前草稿预览，不自动保存。
- 未保存草稿保存在应用私有空间，保存或明确丢弃后删除；孤立草稿最长保留 7 天。
- 原文件同时被其他应用修改时，应用停止直接覆盖并创建冲突副本。
- 带着未保存内容退出时，可选择“保存”“放弃更改”或“取消退出”。

## 阅读模式直接勾选任务

可写的本地文档支持在阅读状态直接点击任务框：

```md
- [ ] 待办事项
- [x] 已完成事项
```

勾选先保留在当前会话中。之后点击编辑并保存，或退出时选择保存，才会写入原文件。

## Markdown 速查

````md
# 一级标题
## 二级标题

- 无序列表
1. 有序列表
- [ ] 待办事项

**加粗**  *斜体*  ~~删除线~~  `行内代码`

[链接](https://example.com)
![图片](images/demo.png)

```python
print("hello markdown")
```
````

数学公式使用内置 KaTeX 渲染：

- 行内公式：`$E = mc^2$`
- 块级公式：`$$\int_{0}^{1} x^{2}\,dx = \frac{1}{3}$$`

不同编辑器对 Mermaid、原始 HTML、宏命令等扩展语法支持不完全一致，显示效果可能略有差异。
