# 常见问题

## 打不开 Markdown 文件

依次确认：

- 文件已经下载完成。
- 文件是真正的 Markdown 或文本，而不是只改了扩展名。
- 来源应用提供了可读取的路径或内容 URI。
- Android 已授予需要的文件访问权限。

可先保存到手机，再从首页“手机存储”选择；需要长期使用时收录到本地仓库。参见[从微信和其他应用打开](02-从微信和其他应用打开.md)。

## “其他应用打开”里没有 MD文件阅读器

重试一次并展开“更多应用”。仍未出现时，把文件保存到本地，再从系统文件管理器打开。如果之前设错默认应用，到系统应用设置中清除原默认值。

## 最近打开中的文件无法访问

原文件可能已移动、删除，或系统授权已失效。点击“重新选择”，定位同一文件即可更新最近记录；不再需要时使用“从最近移除”，不会删除原文件。

## 文档中的图片不显示

- 检查 Markdown 图片地址是否正确。
- 相对图片依赖当前文档所在目录。
- 系统只授权单个外部文件时，应用可能无法读取旁边的图片。
- 网络图片需要可访问的 HTTPS 地址和正常网络。

建议把 Markdown 和相对图片一起放入本地仓库。

## 无法编辑、重命名或删除

文件可能来自只读 URI，或来源没有授予写入权限。使用“收录到本地仓库”创建可管理的副本后再修改。

## 切回浏览模式后，修改没有写入文件

浏览模式只切换到排版预览，不自动保存。回到编辑模式点击保存；直接退出时，在“未保存的更改”提示中选择保存。

## 文档目录没有内容

目录只根据 Markdown 标题生成。请使用 `# 标题`、`## 小节` 等标准标题语法，保存后重新打开目录。

## 阅读位置或书签不见了

位置和书签保存在本机应用数据中，不写入 Markdown，也不参与 Git 同步。清除应用数据、卸载重装或换手机后可能丢失。

## 长图导出失败

长图受设备内存和图片像素限制。文档过长或包含超大图片时，请改用 PDF，或先压缩图片、拆分文档。

## 数学公式没有按预期显示

确认定界符完整，常见写法为 `$...$` 或 `$$...$$`。复杂 LaTeX 宏可能不受支持；可在[分享导出与实用工具](05-分享导出与实用工具.md)中的公式助手先检查。

## 公众号粘贴后格式不一致

不同编辑器对剪贴板 HTML 的解析不同。回到公众号助手切换主题后重新复制。粘贴完成后检查标题、代码块、间距和本地图片；本地图片需要在公众号后台重新插入。

## 思维导图为空或不能导出

- 文档必须包含 H1 到 H6 标题。
- 只能从本地仓库及其子目录选择 Markdown。
- 导出前需按页面提示完成当前文件的激励视频解锁。

## 字体下载失败

检查网络并重试。已下载字体会校验并保存在应用内部；校验失败的文件不会启用。

## Git 同步失败

依次检查：

1. 仓库地址是完整 HTTPS 克隆地址，而不是网页地址或 SSH 地址。
2. 用户名、访问令牌和分支正确。
3. 令牌拥有目标私有仓库的读写权限。
4. 手机网络能够访问对应 Git 服务。
5. 仓库中没有超过服务限制的大文件，且没有依赖 Git LFS。

发生冲突时不要直接删除“冲突副本”，先比较内容。详见[Git 云同步](06-Git云同步.md)。

## 首页或关于页面出现红点

红点表示检测到新版本。进入“关于”并点击“检查更新”，按提示下载或跳转应用商店。应用不会无提示直接安装更新。

## 如何反馈问题

在首页更多菜单选择“意见反馈”，选择问题反馈或功能建议并填写内容。邮箱和微信至少填写一项，方便需要时联系。

提交会附带 App 版本、Android 版本、设备型号和来源页面等基础环境信息；不会自动上传正在阅读的文档、截图或任意文件。页面也提供客服微信二维码。

“关于”页面可查看当前版本、更新入口、应用说明和第三方开源许可。
