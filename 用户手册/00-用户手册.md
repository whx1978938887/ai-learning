# MD文件阅读器用户手册

> 适用版本：MD文件阅读器 1.6.0
> 适用对象：第一次使用本应用打开、阅读、管理或简单修改 Markdown 文档的用户

MD文件阅读器（MDViewer）是一款以本地阅读为主的 Android Markdown 工具。文档默认留在手机上；只有你主动开启 Git 云同步时，本地仓库内容才会同步到你配置的仓库。

## 应用能做什么

- 打开微信、QQ、浏览器、网盘和文件管理器提供的 Markdown 或常见文本文件。
- 阅读标题目录、表格、代码块、任务列表、图片、链接和数学公式。
- 使用连续滚动或电子书式分页阅读，保存阅读位置和书签。
- 在同一张排版画布中做轻量修改，也可切换到源代码模式精确编辑。
- 管理本地仓库，创建笔记，搜索、移动、重命名或删除文件。
- 导出 Markdown 原文件、长图和 PDF，或复制公众号富文本。
- 把 Markdown 转成思维导图，使用公式助手生成 Markdown 公式或 PNG。
- 记录本地文件历史，并可选同步到 Gitee、GitHub 或其他 HTTPS Git 仓库。

## 先记住三件事

1. 需要长期保存、编辑或同步的外部文件，先使用“收录到本地仓库”。
2. 从编辑模式切回浏览模式只会预览，真正写入文件仍需点击“保存”。
3. 重要文档开启本地版本管理，并定期检查备份是否可用。

本目录属于应用内置手册。应用更新后，9 个官方手册文件会更新为新版；请不要把个人内容写进这些文件，可在本地仓库另建笔记。
