# 版本变更记录

这里记录 MD文件阅读器各重要版本中，用户能够直接感知的主要功能变化。版本按从新到旧排列；纯内部调整、渠道配置和仅修复问题的版本不单独列出。

## 1.6.0

- 重做阅读页分页控制、阅读设置和进度抽屉，新增阅读时长信息与更清晰的书签反馈。
- 新增链接操作菜单，长链接显示和图片缩略图在长文档中更加稳定。
- 实用工具新增数学公式助手，思维导图支持更多主题和 XMind 导出。
- 公众号写作助手增加独立文章样式，并重建应用内置用户手册。

## 1.5.1

- 新增“实用工具”入口，集中提供公众号写作助手和 Markdown 思维导图。
- 公众号写作助手支持选择 Markdown 文件、预览排版并复制富文本。
- 思维导图支持导出图片，分享与导出时统一使用更清晰的目标位置选择器。

## 1.5.0

- 新增所见即所得式的格式化编辑模式，可直接修改标题、段落、列表和代码块。
- 支持插入、删除、撤销等块级操作，同时保留源代码模式用于精确编辑。
- Git 仓库历史增加查看和安全回退能力，恢复时保留现有版本。

## 1.4.0

- 新增本地文件版本管理，可自动记录本地仓库中的文件变化。
- 支持按文件查看历史、比较差异、创建备注版本并恢复旧内容。
- 删除或恢复操作会保留可追溯记录，关闭版本管理也不会删除既有历史。

## 1.3.3

- 优化阅读模式的顶部与底部控制，长文档翻页和模式切换更顺手。
- 改进搜索、重命名和编辑保存衔接，减少位置或未保存内容丢失。

## 1.3.2

- 在编辑器中粘贴网页或富文本时，可自动转换为 Markdown。
- 普通纯文本仍按原内容粘贴，不会被额外改写。

## 1.3.1

- 新增沉浸式横向分页阅读，支持页码、手势翻页、图片缩放和阅读位置恢复。
- 最近打开列表增加批量整理和文件操作，外部文件可收录到本地仓库。
- Git 云同步增加 GitHub 预设，并优化本地仓库与首页导航。

## 1.3.0

- 新增 Git 云文件管理，可将本地仓库同步到自己的私有 Git 仓库。
- 支持拉取、推送、自动同步、首次关联方向选择和冲突副本保留。
- 云同步默认关闭，只使用本地版本管理时不会上传文档。

## 1.2.1

- 阅读页中的 Markdown 任务框可以直接勾选，并在保存时写回原文档。
- 优化阅读设置、工具栏和字体下载体验，浏览与编辑字号衔接更一致。

## 1.2.0

- 重做首页、文件列表和阅读页视觉样式，常用操作更集中。
- 支持通过系统文件选择器打开本地文档，并改进新建笔记与文件信息界面。
- 优化阅读字体、标题栏和本地文件浏览流程。

## 1.1.6

- 新增长图、PDF、HTML 和 Markdown 原文件等分享导出方式。
- 改进长图拼接、PDF 版式和分享菜单，导出结果更适合移动端使用。

## 1.1.5

- 意见反馈升级为应用内表单，可填写问题、建议和联系方式。
- 改进阅读页轻量编辑流程，并完善提交成功与错误提示。

## 1.1.3

- “关于”页面增加更清晰的版本与更新入口。
- 根据安装渠道提供对应的下载更新或应用市场跳转方式。

## 1.1.2

- 新增启动后自动检查更新和新版提示。
- 支持默认渠道下载安装包更新，商店渠道则跳转对应应用市场。

## 1.1.0

- 阅读页新增轻量编辑、主题切换和富文本复制，阅读后可直接做小修改。
- 改进微信、下载目录和系统文件管理器中的外部 Markdown 打开流程。
- 完善存储权限引导与相对图片解析，常见来源文件打开更稳定。

## 1.0.2

- 新增首次启动隐私同意流程，并补充本地存储权限说明。
- 增加多套 Markdown 阅读主题，优化外部文件兼容性。

## 1.0.0

- 首次发布 MD文件阅读器，支持从其他应用打开 Markdown 和常见文本文件。
- 提供独立阅读页、标题目录、文档内搜索和相对图片显示。
- 以阅读为默认入口，并保留用于小修正的轻量编辑能力。
