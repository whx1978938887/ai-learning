# 分享导出与实用工具

## 分享和导出当前文档

浏览模式从更多菜单选择“分享”；阅读模式点击底部“分享”。两处会打开相同的输出面板。

![阅读页分享与导出面板](https://hupingzhi.cn/materials/asset_3b6cc2239b0e4fc2958263469d8d7171/05-tools-01-share.png)

可用项目取决于文件来源和当前状态：

- **导出 Markdown 原文件**：原样分享当前 `.md` 文件；只读内容 URI 可能不提供。
- **导出长图**：把当前渲染效果生成 PNG 并打开系统分享；文档过长时改用 PDF。
- **导出 PDF**：把渲染效果分页生成 PDF，更适合长文档。
- **发布到公众号**：进入公众号写作助手，预览后复制富文本。

长图和 PDF 默认包含 MD文件阅读器来源尾注。可在“用户设置”完整观看激励视频，去除当天导出文件的来源尾注。

## 工具箱

点击首页底部“工具箱”，可以使用三项独立工具。

![工具箱首页](https://hupingzhi.cn/materials/asset_30a864ec7c96439cb5a6f9a7fcfca366/05-tools-02-toolbox.png)

### 微信公众号写作助手

1. 进入工具箱，选择“微信公众号写作助手”。
2. 从本地仓库选择 Markdown 文件。
3. 选择公众号主题并检查预览。
4. 完整观看一条激励视频后复制当前文件的富文本。
5. 粘贴到公众号编辑器后，检查标题、段落、代码和图片位置。

![微信公众号写作助手预览](https://hupingzhi.cn/materials/asset_aa9df4cbc828405abddd6a805a16cb2d/05-tools-03-wechat-assistant.png)

注意：

- 助手只选择本地仓库及其子目录中的 Markdown。
- 不同富文本编辑器处理剪贴板 HTML 的方式不同，粘贴后必须检查。
- 本地图片不会随富文本自动上传到公众号，需要在公众号后台重新插入。
- 当前文件解锁后可在本次使用中重复复制；具体提示以页面为准。

### Markdown 转思维导图

1. 选择本地仓库中的 Markdown。
2. 应用把 H1 到 H6 标题转换为导图节点。
3. 选择中心向两侧、从左到右或从上到下布局。
4. 选择视觉模板，使用拖动、双指缩放和双击适屏查看。
5. 完整观看激励视频后，可为当前文件导出 XMind、FreeMind 或 PNG。

![Markdown 思维导图预览](https://hupingzhi.cn/materials/asset_91c7d0413c424c34bb2623f905a644c3/05-tools-04-mindmap.png)

没有可转换标题时，请先在文档中加入 `#` 到 `######` 标题。XMind 和 FreeMind 适合继续编辑，PNG 适合直接分享。

### 数学公式助手

1. 输入 LaTeX 源码，或点击常用结构、符号和希腊字母模板。
2. 选择行内 `$…$` 或块级 `$$…$$` 模式。
3. 检查实时公式和 Markdown 预览。
4. “复制 Markdown”可直接复制到文档。
5. 完整观看激励视频后，本次使用期间可以保存或分享透明/白底 PNG。

![数学公式助手](https://hupingzhi.cn/materials/asset_7d1869f8243f4b7eb820271dc9d60182/05-tools-05-formula.png)

公式源码最长 4000 字符；渲染尺寸过大或定界符不完整时，页面会要求调整后重试。

## 选择导出格式

不同任务建议使用不同格式：

![工具中的导出格式选择](https://hupingzhi.cn/materials/asset_0c83db17fe294f269be410d4b8841729/05-tools-06-export-choice.png)

- 保留原文继续编辑：Markdown 原文件。
- 手机聊天快速查看：PNG 长图。
- 长文档归档或打印：PDF。
- 粘贴到公众号：公众号富文本。
- 继续编辑导图：XMind 或 FreeMind。
- 分享导图或公式：PNG。

## 广告与解锁说明

- 完整观看激励视频后，当天可关闭 Banner 和信息流广告。
- 去广告和去除导出尾注按本地日期计算，次日恢复。
- 公众号复制、思维导图导出和公式图片导出按各工具页面说明解锁。
- 广告未成功完成时不会授予对应权益，可检查网络后重试。
