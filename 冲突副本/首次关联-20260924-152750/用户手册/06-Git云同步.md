# Git 云同步

Git 云同步是可选功能，默认关闭。只开启本地版本管理时，文档不会上传网络；开启 Git 云同步后，本地仓库内容会同步到你指定的私有仓库。

## 使用前准备

- Android 6.0 或更高版本。
- 已开启本地版本管理。
- 一个专门用于文档备份的私有仓库。
- HTTPS 仓库地址、Git 用户名和具备必要读写权限的访问令牌。
- 稳定网络，首次同步建议使用 Wi-Fi。

不要把访问令牌写进仓库地址、Markdown 文档或聊天消息。令牌疑似泄露时，立即到 Git 服务商撤销并重新创建。

## 通用配置流程

1. 在首页更多菜单或“用户设置”进入“版本管理与 Git 云同步”。
2. 先开启“本地版本管理”，再开启“Git 云文件管理”。
3. 选择 Gitee、GitHub 或“其他 HTTPS Git”。
4. 填写 HTTPS 仓库地址、Git 用户名、访问令牌和分支。
5. 点击“仅测试连接”验证参数，或使用“测试并保存”。
6. 本地和远端都有内容时，按提示选择首次同步方向。
7. 完成首次同步后，到仓库网页确认文件已经出现。

## Gitee 完整示例

### 1. 创建私有空仓库

在 Gitee 新建仓库，例如 `mdviewer-notes`：

- 可见范围设为“私有”。
- 建议不要初始化 README、许可证或 `.gitignore`。
- 创建后复制 HTTPS 克隆地址，例如：

```text
https://gitee.com/你的用户名/mdviewer-notes.git
```

不要填写网页浏览地址、SSH 地址，也不要把用户名或令牌拼进 URL。

### 2. 创建访问令牌

在 Gitee 个人设置中创建访问令牌：

- 名称可填写“MD文件阅读器备份”。
- 只授予目标私有仓库所需的读写权限。
- 创建后立即复制并妥善保存；令牌通常只完整显示一次。

### 3. 填写应用配置

在应用中选择 Gitee，并填写：

- HTTPS 仓库地址。
- Gitee 用户名。
- 访问令牌。
- 实际分支名；空仓库通常可使用 `main`。

连接测试成功后保存并执行首次同步。

## GitHub 和其他 HTTPS Git

- GitHub 建议使用只授权目标仓库、具备 Contents 读写权限的 fine-grained personal access token。
- 其他服务需支持标准 HTTPS Git 用户名/令牌认证。
- 当前不支持 SSH 地址和 Git LFS。
- 不同服务的文件与仓库大小限制不同，应用会按内置服务规则提前阻止明显超限的同步。

## 首次同步方向

- **手机内容完整、远端为空**：以本地为主，推送到远端。
- **新手机接入已有仓库**：以远端为主，拉取到手机。
- **双方都有内容**：根据页面提示选择主版本；另一方会保留为冲突副本，不直接丢弃。

## 日常同步

关联成功后，可以点击首页底部“同步仓库”立即同步，也可以开启本地变化后自动同步、每日补偿同步和仅 Wi-Fi 自动同步。

![首页同步状态与分支信息](https://hupingzhi.cn/materials/asset_c2078279523e4f8ebf9af31af428228e/06-git-02-sync-status.png)

建议在重要编辑前后各同步一次，并定期到远端仓库确认备份确实存在。

## 冲突和解除关联

同一文件在本地和远端同时修改时，应用会保留主版本，并把另一版本放入“冲突副本”目录。请比较后保留正确内容，再删除不需要的副本并重新同步。

“解除 Git 云关联”会清除应用中保存的访问令牌和远端配置，但保留本地文档、本地历史和远端已有文件。

同步失败的检查顺序见[常见问题](07-常见问题.md)。
