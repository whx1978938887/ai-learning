# 从微信和其他应用打开 Markdown 文件

## 从微信打开

1. 在微信聊天、文件传输助手或群聊中点击 `.md` 文件，等待下载完成。
2. 在文件预览页点击右上角 `...`。
3. 选择“其他应用打开”。
4. 在系统列表中选择“MD文件阅读器”。
5. 第一次建议选择“仅一次”，确认能正常打开后再决定是否设为默认。

微信版本和手机系统界面可能略有差异。如果看不到“其他应用打开”，可长按文件查找该入口，或先将文件保存到手机。

## 从系统文件管理器打开

1. 在微信、QQ、浏览器或网盘中把文件保存到手机。
2. 打开系统“文件管理”或“文件”应用。
3. 在“下载”“最近文件”或来源应用目录中找到文件。
4. 点击文件，在打开方式中选择 MD文件阅读器。

![Android 系统打开方式选择器](https://hupingzhi.cn/materials/asset_6fd27606de66418b953ef638ad8bc17a/02-external-open-01-system-chooser.png)

也可以直接进入 MD文件阅读器，点击“手机存储”，再从系统选择器找到文件。

## 收录到本地仓库

从其他应用打开的文件可能只有临时或只读权限。阅读页顶部出现“收录到本地仓库”时，建议对需要长期使用的文件执行收录。

![外部文件阅读页的收录入口](https://hupingzhi.cn/materials/asset_30937901d7c948aeb2f76bc13fa03b33/02-external-open-02-reader-collect.png)

收录后应用会：

1. 把当前文件复制到本地仓库。
2. 同名时生成不冲突的文件名，不覆盖已有文件。
3. 切换到本地副本继续阅读。
4. 已开启 Git 云同步时，安排同步新副本。

![收录后位于本地仓库的文件](https://hupingzhi.cn/materials/asset_a9a43b8164e8476a9d492f0a8fb83f08/02-external-open-03-collected-copy.png)

## 如果选错了默认应用

1. 打开手机“设置”。
2. 进入“应用”或“应用管理”。
3. 找到之前误设为默认的应用。
4. 进入“默认打开”或类似设置，清除默认值。
5. 回到文件来源，重新执行“其他应用打开”。

## 常见限制

- 来源只授予读取权限时，不能直接编辑、重命名或删除。
- 系统只授权单个文件时，同目录相对图片可能无法读取。
- 文件移动、删除或授权失效后，“最近打开”会要求重新选择。
- 微信里没有列出本应用时，先保存到本地，再从系统文件管理器打开。
- 文件必须是真正的 Markdown 或文本内容；只改扩展名不会把其他格式转换成 Markdown。

更多排查方法见[常见问题](07-常见问题.md)。
